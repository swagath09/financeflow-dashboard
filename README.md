# 💰 FinanceFlow Dashboard

A modern finance dashboard built using React to track income, expenses, and spending patterns.

---

## 🌐 Live Demo  
https://financeflow-dashboard.netlify.app

---

## 🚀 Features

- Dashboard with Balance, Income, Expenses  
- Line chart for balance trend  
- Doughnut chart for spending categories  
- Transactions table with search and filter  
- Insights section  
- Basic role-based UI  
- Responsive design  

---

## 🛠 Tech Stack

- React.js  
- JavaScript (ES6+)  
- HTML5  
- CSS3  
- Chart.js  
- React Chart.js 2  
- Lucide React  
- Vite  
- Git & GitHub  
- Netlify  

---

## ⚙️ How It Works

- Uses React state for navigation and data  
- Uses conditional rendering for page switching  
- Uses Chart.js for visualization  
- Uses mock data for transactions  

---

## ▶️ Run Locally

npm install  
npm run dev
